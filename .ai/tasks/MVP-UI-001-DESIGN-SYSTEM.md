# Task MVP-UI-001-DESIGN-SYSTEM

## Objective

Membangun fondasi UI dan design system Wedding System untuk pasar Indonesia.

## Actor

Pelanggan, tamu, vendor, dan administrator.

## In scope

- Color tokens
- Typography
- Spacing
- Radius
- Shadow
- Buttons
- Inputs
- Textarea
- Select
- Checkbox
- Radio
- Dialog
- Drawer
- Toast
- Alert
- Badge
- Empty state
- Loading state
- Error state
- Skeleton
- Application shell
- Design-system showcase

## Out of scope

- Landing page final
- Payment
- Authentication
- Invitation templates final
- Backend integration

## Acceptance criteria

- Mobile-first
- Bahasa Indonesia
- Keyboard accessible
- Visible focus
- Responsive
- Reduced motion
- No generic AI visual patterns
- Browser tested
- Build and tests pass
