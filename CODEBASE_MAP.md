# Codebase Map

`apps/web`: customer, admin, public invitation routes. `packages/domain`: rules. `packages/application`: use cases/ports. `packages/contracts`: Zod transport/event contracts. `packages/database`: Prisma schema/repositories. `packages/template-engine`: canonical view model and registry. `packages/ui`: accessible primitives. `packages/providers`: payment, email, WhatsApp, storage adapters. `.agents`, `.skills`, `.claude/rules`, `.ai`: agentic delivery system.
