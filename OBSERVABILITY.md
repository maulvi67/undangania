# Observability

Use OpenTelemetry-compatible traces, metrics, and logs. Correlate request, use case, database, outbox, job, and provider call. Monitor request latency/errors, database connections/queries, queue depth/retries/DLQ, payment mismatch, webhook failure, notification delivery, domain verification, media processing, invitation publication, and RSVP success. Telemetry uses allowlisted non-PII attributes.
