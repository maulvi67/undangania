# Authorization Matrix

Customer OWNER controls wedding and billing; EDITOR manages content/guests but not refunds/ownership; VIEWER is read-only; FINANCE accesses billing only. Vendor roles access only assigned vendor/printing resources. SUPPORT sees masked diagnostics with approved elevation. ADMIN console access requires an authenticated session with an active ADMIN membership; privileged ADMIN mutations require MFA step-up, reason, and audit. Guests are token-scoped only.
