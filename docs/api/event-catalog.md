# Event Catalog

Versioned events: UserRegistered, WeddingCreated, TemplatePurchased, PaymentConfirmed, EntitlementGranted, InvitationPublished, GuestImported, RsvpSubmitted, GuestbookSubmitted, MediaUploaded, MediaScanning, MediaProcessing, MediaReady, MediaRejected, MediaDeleted, PrintingOrderCreated, ProofApproved, PrintingOrderShipped, NotificationRequested, NotificationDelivered, DomainActivated, SubscriptionRenewed, AiDraftGenerated, AnalyticsEventAccepted. Consumers must be idempotent and tolerate additive fields. `AnalyticsEventAccepted` contains only the analytics schema version, event name, tenant/actor hashes, allowlisted scalar properties, and UTC occurrence time; it never carries raw contacts, tokens, content, URLs, or client request metadata.
