# Event Catalog

Versioned events: UserRegistered, WeddingCreated, TemplatePurchased, PaymentConfirmed, EntitlementGranted, InvitationPublished, GuestImported, RsvpSubmitted, GuestbookSubmitted, MediaReady, PrintingOrderCreated, ProofApproved, PrintingOrderShipped, NotificationRequested, NotificationDelivered, DomainActivated, SubscriptionRenewed, AiDraftGenerated. Consumers must be idempotent and tolerate additive fields.
