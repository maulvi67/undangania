# Security Guidelines

Least privilege, MFA for privileged users, secure cookies, CSRF protection, CSP, HSTS, server validation, output encoding, rate limiting, tenant-scoped repositories, token hashing, signed uploads, webhook signature/replay protection, encryption, secret management, audit, data minimization, and incident response.

Never log guest contacts, gift account values, tokens, cookies, raw payment payloads, or AI prompts containing personal data. Review Indonesian personal-data obligations before production and document processors/transfers.
