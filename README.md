# Wedding System MVP MCP + Skills

MVP-focused Next.js skeleton and Claude Code operating system for an Indonesian wedding platform. Includes template marketplace, invitation editor/renderer contracts, wedding/event, guest/RSVP/guestbook, gift/gallery, order/payment, admin baseline, MCP runtime tools, UI/UX skills, least-privilege rules, orchestration, tests, and validation.

## Start

```bash
cp .env.example .env
docker compose up -d
npm install
npm run validate:repo
npm run dev
```

Read `AGENTS.md`, `MVP_IMPLEMENTATION_GUIDE.md`, and `.ai/tasks/TASK_TEMPLATE.md` before changes.
