# Coding Standards

TypeScript strict, named domain concepts, small pure functions, no hidden I/O, no direct Prisma outside repositories, no provider DTO leakage, no business rule in React components, errors are typed, logs are structured and PII-safe, comments explain decisions, and dependency additions require purpose/license/security/bundle review.

Tests accompany rules and regressions. Changes reference task and requirement IDs. Format with Prettier and lint through workspace scripts.
