# Product Requirements

## Personas

Couple owner, collaborator, guest household, wedding organizer, vendor operator, template designer, reseller, support agent, finance operator, moderator, and platform administrator.

## Critical journeys

1. Browse templates → purchase → payment verified → workspace provisioned.
2. Configure couple/events/content → preview → publish → custom/public URL.
3. Import guests → generate personalized links → RSVP/guestbook → export.
4. Add printing products → approve proof → vendor accepts → production → shipping.
5. Subscribe/upgrade/extend → entitlement and limits change after verified payment.
6. Generate AI draft → review factual inputs → edit → approve → save/publish manually.

## Non-functional requirements

Mobile-first, accessible, secure multi-tenancy, idempotent payments/notifications, auditability, graceful provider failure, Indonesian locale/IDR/timezones, observable operations, recoverable backups, and predictable costs.

## MVP success

Paid order completion, invitation publication, guest link access, RSVP success, operational payment reconciliation, no cross-tenant access, and production QA for at least three original/licensed templates.
